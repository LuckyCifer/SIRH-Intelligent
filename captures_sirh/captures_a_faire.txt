CAPTURES A REALISER POUR LE RAPPORT DE STAGE
=============================================
Resolution : 1920x1080 — Format : PNG — Navigateur : plein ecran
Comptes demo : lucky (RH) | manager.it (Manager) | alice.mballa (Employe)

PREREQUIS AVANT LES CAPTURES :
- Demarrer MySQL + Django (port 8000) : cd backend && venv\Scripts\activate && python manage.py runserver
- Demarrer Vite (port 5173)           : cd frontend && npm run dev
- Ouvrir Chrome -> localhost:5173

PROCEDURE CAPTURE :
1. Se connecter avec le compte indique
2. Naviguer vers la page
3. Win+Shift+S -> selectionner toute la page
4. Coller dans Paint -> Enregistrer en PNG
5. Nommer exactement imageX.png et placer dans ce dossier
